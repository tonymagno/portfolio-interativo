A premium, animated, recruiter-ready portfolio built to showcase real-world delivery, interface quality, and technical range across frontend, automation, support, and full-stack projects.

## Overview

This portfolio was designed as a professional presentation layer for:

- recruiters evaluating technical capability
- clients reviewing completed work
- LinkedIn visitors scanning for credibility
- potential partners looking for a clear service offering

It combines motion design, clean information architecture, responsive layout, featured projects, and an AI assistant to improve engagement and discovery.

## What this portfolio demonstrates

- Modern React architecture with TypeScript
- Responsive UI built for desktop and mobile
- Motion design using Framer Motion and GSAP
- AI assistant integration for interactive engagement
- Real project showcase with live links and GitHub repositories
- Professional positioning for freelancing and job applications
- Strong visual identity with a premium, polished look

## Key features

- Animated hero section with strong personal branding
- Project gallery with real published work
- About section with skill grouping and professional summary
- Contact section with direct communication paths
- Floating AI chatbot for quick interaction
- Theme-aware design system with reusable UI primitives
- Accessible markup and responsive layout patterns
