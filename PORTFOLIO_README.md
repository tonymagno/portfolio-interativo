# Portfólio Interativo com Chatbot IA\n\nPortfólio profissional interativo com animações avançadas e chatbot inteligente integrado com Google Gemini 2.5 Flash API.\n\n## 🎯 Características Principais\n\n### Animações Avançadas\n- **GSAP 3**: Animações sincronizadas com scroll e efeitos complexos\n- **Framer Motion**: Transições suaves e animações de componentes React\n- **ScrollTrigger**: Ativa animações ao entrar na viewport\n- **Lenis**: Scroll suave e fluido em toda a página\n\n### Chatbot IA\n- **Google Gemini 2.0 Flash**: Respostas inteligentes sobre projetos e experiência\n- **Conversas em Tempo Real**: Chat flutuante com histórico de mensagens\n- **Contexto Profissional**: Treinado com informações do portfólio\n\n### Design Sofisticado\n- **Minimalismo Sofisticado**: Espaço negativo como protagonista\n- **Tipografia Estratégica**: Poppins para display, Inter para corpo\n- **Paleta Monocromática**: Acentos em gradiente azul-roxo\n- **Responsivo**: Mobile-first com suporte completo a desktop\n\n## 🚀 Stack Técnico\n\n### Frontend\n- React 19 com TypeScript\n- Vite 7 como bundler\n- TailwindCSS 4 para styling\n- Framer Motion para animações\n- GSAP 3 com ScrollTrigger\n- Lenis para smooth scroll\n\n### Backend (Opcional)\n- Node.js com Express\n- PostgreSQL ou MongoDB\n- Docker para containerização\n\n### IA\n- Google Generative AI SDK\n- Gemini 2.0 Flash Model\n\n### Ferramentas\n- Git para versionamento\n- Prettier para formatação\n- TypeScript para type safety\n\n## 📦 Instalação\n\n### Pré-requisitos\n- Node.js 18+\n- npm ou pnpm\n- Chave de API do Google Gemini\n\n### Passos\n\n1. **Clonar repositório**\n```bash\ngit clone https://github.com/seu-usuario/portfolio-interativo.git\ncd portfolio-interativo\n```\n\n2. **Instalar dependências**\n```bash\npnpm install\n```\n\n3. **Configurar variáveis de ambiente**\n```bash\ncp .env.example .env.local\n```\n\nAdicione sua chave de API do Gemini:\n```env\nVITE_GEMINI_API_KEY=sua_chave_aqui\n```\n\n4. **Iniciar servidor de desenvolvimento**\n```bash\npnpm dev\n```\n\nO site estará disponível em `http://localhost:3000`\n\n## 📁 Estrutura
